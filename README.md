## iOS 下载低版本应用，历史版本app

部分脚本无法适用于新版app

参考：

- [iOS任意版本号APP下载v6.0 - 吾爱破解](https://www.52pojie.cn/thread-1756628-1-1.html)
- [iOS 安装老版本软件 - bilibili](https://www.bilibili.com/video/BV1azXnYHEqr/)

>iOS任意版本号APP下载v6.0
>蓝奏：https://wwl.lanzn.com/i9yo41oi30mj
>
>iTunes v12.6.5.3 下载
>64位：https://secure-appldnld.apple.com/itunes12/091-87819-20180912-69177170-B085-11E8-B6AB-C1D03409AD2A6/iTunes64Setup.exe

步骤：
1. 手机下载app，主要是要购买这个项目
2. iTunes登录和手机同一个用户，这样是官方签名的。iTunes可用通过账户、已购买来下载，下载好后在资料库，左上有个“音乐”，点击切换为应用就能找到
3. 先别急着下载，工具里搜索app，双击进入版本，双击开始拦截
4. iTunes点击下载，iTunes右上角下载图标点击暂停，工具查看拦截成功，工具点击停止拦截，iTunes点击下载
5. iTunes资料库，拖拽app到电脑文件夹，再托进i4助手文件管理，双击安装




## iOS 签名安装ipa文件

拿到别人提供的ipa文件如何安装？

巨魔，iOS26系统版本过高，不支持，只能使用签名安装各app

参考[iOS 安装老版本软件 - bilibili](https://www.bilibili.com/video/BV1azXnYHEqr/)前半部分，一次签名不成功再多签名几次

安装后手机验证app，可用用wifi、流量都试试

最后[iOS26 打开开发者模式](https://www.bilibili.com/video/BV1WZHGzmErL/)

前面安装历史版本，是官方签名，永久有效期，但是这里的签名有效期只有7天
